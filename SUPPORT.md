## 2. GitHub Issues

* **Bug Reports**: If you find a bug, please check [open issues](https://github.com/shs3131/H-runner/issues) to avoid duplicates, then submit a detailed bug report using our issue template.
* **Feature Requests**: We welcome ideas for improvements! Please open an issue outlining your proposal.
